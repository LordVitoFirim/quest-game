# quest-game

Этот проект подготовлен как отдельный репозиторий с публикацией через GitHub Pages.

## Что должно быть в репозитории

В корне репозитория должны лежать:

- `index.html`
- `.github/workflows/deploy-pages.yml`
- `README.md`

## Как опубликовать

1. Создай на GitHub новый репозиторий `quest-game`.
2. Загрузи в него содержимое этой папки `quest-game`.
3. Убедись, что основная ветка называется `main`.
4. Открой в GitHub: `Settings` -> `Pages`.
5. В поле `Source` выбери `GitHub Actions`.
6. Сделай `git push` в ветку `main`.

После этого сайт будет опубликован автоматически.

## Адрес сайта

Если репозиторий называется `quest-game`, адрес будет таким:

`https://<github-username>.github.io/quest-game/`
