# quest-game

Этот проект подготовлен как отдельный репозиторий с публикацией через GitHub Pages без workflow.

## Что должно быть в репозитории

В корне репозитория должны лежать:

- `index.html`
- `.nojekyll`
- `README.md`

## Как опубликовать

1. Убедись, что код находится в ветке `main`.
2. Открой в GitHub: `Settings` -> `Pages`.
3. В поле `Source` выбери `Deploy from a branch`.
4. В поле `Branch` выбери `main`.
5. В поле папки выбери `/(root)`.
6. Нажми `Save`.

После этого GitHub Pages опубликует сайт из корня репозитория.

## Адрес сайта

Если репозиторий называется `quest-game`, адрес будет таким:

`https://<github-username>.github.io/quest-game/`
